# Lab 1 - Cyber Threat Intelligence

## Lab Purpose

This lab is a Cyber Threat Intelligence report. It analyzes a real Microsoft
Threat Intelligence article about Storm-2755 and maps the attack behavior to
MITRE ATT&CK techniques.

The goal is to understand how a real attack works, summarize the attack chain,
and connect each step to a known ATT&CK tactic and technique.

## Main Work

The full report is in:

- `lab1.md`

The report includes:

- short attack summary
- attack diagram and sequence
- MITRE ATT&CK mapping table
- defensive insights and lessons learned
